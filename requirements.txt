# THIS FILE IS WHAT STREAMLIT COMMUNITY CLOUD INSTALLS. It looks for
# `requirements.txt` by name and cannot be pointed at another file, so anything

#
# To run the pipeline (toxic-bert, the TFT, the embedder, clustering):
#     pip install -r requirements-train.txt
#
# To run only the dashboard or the API:
#     pip install -r requirements.txt
